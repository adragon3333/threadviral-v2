# Mẫu giọng ThreadViral

35 file MP3 tiếng Việt, gồm 3 giọng CapCut và 32 giọng VieNeu Pro, được lấy từ URL nghe thử quan sát trong phiên đăng nhập được người dùng cho phép.

Mở index.html để nghe và tìm kiếm offline. catalog.json có tên, source ID, SHA-256, thời lượng và URL nguồn. Các MP3 chỉ chứa đoạn mẫu cố định (khoảng 3–5 giây); đây không phải model hoặc dịch vụ tổng hợp giọng. Không có API key/cookie trong bộ tài nguyên.

Studio hiện vẫn dùng Hoài My/Nam Minh cho lời đọc mới. Các giọng mẫu không được gán giả sang hai giọng này.
